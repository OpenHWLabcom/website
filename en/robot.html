Get control accessKewes BaJie robot

The control interfaces of the BaJie arm (mvp03 6-axis arm + lift column + head pitch + gripper) are available to lab-network members and authorised partners. Apply using the steps below; after approval you receive device addresses, accounts and console access.

  1. Eligibility: join the OpenHW Lab local-lab network, or own / borrow a BaJie device.
  2. Apply: email your organisation / contact / device model / use case / network environment.
  3. Review & authorise: we confirm the use case and safety conditions; access to the Jetson console, robot LAN and lower-board SSH is granted as needed.
  4. Safety briefing: read and confirm the motion safety rules (E-stop, limits, grasp rules).
  5. Docs & integration: download the API reference; we support the integration.

Three steps:
  1. Unzip and edit paths plus ROBOT_HOST / ROBOT_PW in host/serve.sh.
  2. On the host run bash host/serve.sh, open http://<jetson-ip>:8790/robot_home.html.
  3. Put lower/jogd on the lower board and start jtstream.py to connect ROS 2.
Read docs →

No robot? You can still open arm3d.html and other pages with a local static server to explore the 3D model and UI.

⚠️ Safety: the arm is a powerful real machine. Clear the workspace, keep the E-stop in hand, and validate unloaded at slow speed first. Always approach grasps from above. See docs/MOTION_RULES.md and docs/GRASP_RULES.md.

Verify & Version

Verify: Windows (PowerShell) Get-FileHash .\openhwlab-robot-arm.zip -Algorithm SHA256; macOS / Linux sha256sum openhwlab-robot-arm.zip. Matches the SHA-256 above → intact official package.
