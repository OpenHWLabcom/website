Our Approach vs Off-the-shelf Systems

In one line: we don't reflash/replace the OS — we add an open-source service stack to your stock box. No flashing, reversible, keeps the stock system, one package + adb, done in minutes.

Quick map: the market roughly splits into three — ① Brand NAS devices (Synology DSM / QNAP QTS / lightweight "private cloud" boxes); ② Open-source / DIY NAS OS (OpenMediaVault, TrueNAS, CasaOS, unRAID …); ③ Reflash-style box systems (turn the box into a pure Linux mini-server/router, e.g. Armbian/OpenWrt). We're a fourth path: leave the stock Android untouched, run an Ubuntu chroot "sidecar" + our services.

What we can build (roles)

  • Print server: old USB printer → network printing (IPP + AirPrint + QR print + auto driver).
  • Downloader + NAS: aria2 downloads + Samba share + DLNA (drive-first auto storage).
  • Surveillance recorder: USB camera live + loop recording + remote + motion alerts.
  • Game console / mini PC / ad-block DNS / KTV and more.

What makes ours different

  • No flash, reversible: stock system fully preserved; remove the chroot to revert.
  • Very low barrier: your PC only needs adb; generic projects also ship a full offline package (system+deps bundled, box needs no internet).
  • Multi-model: one method fits many boxes (tested on 魔百盒 CM201-1 / CM201-2 / M301H, HiSilicon Hi3798MV300).
  • Open source: MIT, source + guides public, fork-friendly.

What we don't do

  • Multi-bay RAID / snapshots / redundancy → use a brand NAS or an open NAS OS.
  • Real-time media transcoding / many concurrent users → old box CPU can't.
  • Turning the box into a pure Linux host with a custom kernel → that's the "reflash" path.
  • ⚠️ Don't store critical data on a box NAS (single disk, no redundancy, old stack).
Bottom line: Brand NAS / open NAS OS = purpose-built for storage; reflash-style box systems = replace (more power & freedom, but flashing, brick risk, stock features lost); ours = add-on (a good-enough lightweight server from an idle box — stable, cheap, reversible, stock kept).

FAQ

Any requirement on my PC's OS?

Barely. Linux / macOS are easiest (just install adb); Windows works too (run scripts in WSL or Git Bash, or follow the guide and type the adb commands). PC architecture (x86/arm64) doesn't matter. The one that matters is the box (Android + its arch, e.g. armv7/armhf).

Is this the same as "reflashing a box into a NAS"?

No. Reflashing replaces the box's whole OS (pure Linux); we don't flash — we run a chroot sidecar + our services inside the stock system.

Is my data safe?

Box solutions are usually single-disk, no RAID, old kernel — not for critical data. Use a real NAS for reliable storage.
