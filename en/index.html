How it works

  1. Download the kit .zip you want and unzip it.
  2. Read the included Install-Guide.pdf (illustrated, ~30–60 min).
  3. Connect the box (enable ADB) and run install/one-click-install.sh <box-ip>, or follow the guide manually.
Requires: a rooted Android TV box with ADB enabled.
We do not flash firmware or touch system partitions — uninstall the apk / re-enable disabled apps to fully revert.
Read the guides →

FAQ

Does it phone home / upload my data?

Everything runs locally on the device, nothing goes to the cloud. Only features you set up yourself (file transfer, remote view, alerts) use your own network.

Which boxes are supported?

Rooted Android TV boxes (Android 4.4+, armv7 / arm64). Tested on HiSilicon Hi3798MV100 and ZTE ZX296715. Other models will likely work.

Is it free?

Completely free and open source (MIT).

What if I mess it up?

No flashing and no partition changes — just uninstall the apk / re-enable the apps you disabled.

Can I contribute / build on it?

Absolutely. Each kit ships a developer-docs/source folder; the repos host source and guides too. Issues and PRs welcome.
