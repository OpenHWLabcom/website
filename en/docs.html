Guides & Docs

Every kit ships an illustrated Install-Guide.pdf. Below is the general workflow, then per-kit guides and developer docs.

General workflowDo this first, for any kit

  1. Check your model: an Android TV box (Android 4.4+, armv7/arm64) that is rooted.
  2. Enable ADB: turn on USB/network debugging in Developer Options; install adb on your PC.
  3. Connect: adb connect <box-ip>:5555 (or use a USB cable).
  4. Download & unzip the kit you want.
  5. Run one-click install: in install/, run ./one-click-install.sh <box-ip>; or follow Install-Guide.pdf manually.
  6. Reboot & verify: set the app as boot launcher per the guide; it should start automatically.
⚠️ Safety: we do not flash firmware or touch system partitions. All changes live at the app layer and under /data — uninstall the apk / re-enable disabled system apps to revert.
