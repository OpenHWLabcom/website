我们的方案 vs 市面上的系统

一句话：我们不是"重装/刷机换系统"，而是给原厂盒子"加装"一套开源服务—— 不刷机、可逆、保留原厂功能，一个安装包 + adb 几分钟搞定。

快速看懂：市面上的方案大致三类 —— ① 品牌 NAS 设备（群晖 DSM / 威联通 QTS / 绿联、极空间等轻 NAS）； ② 开源/DIY NAS 系统（OpenMediaVault、TrueNAS、CasaOS、unRAID …）； ③ 刷机式盒子系统（把盒子刷成 Armbian / OpenWrt 等纯 Linux 小主机/软路由）。 我们是第四条路：原厂 Android 不动，用 chroot"旁路"跑 Ubuntu 子系统 + 我们的服务。

我们能做到什么（角色）

  • 打印机服务器：老 USB 打印机变网络打印（IPP + AirPrint + 扫码打印 + 驱动自适应）。
  • 下载机 + NAS：aria2 挂机下载 + Samba 家庭网盘 + DLNA（插盘优先存储自动切换）。
  • 监控录像主机：USB 摄像头直播 + 循环录像 + 远程看 + 移动侦测/告警。
  • 游戏机 / 电脑主机 / 去广告 DNS / KTV 点歌台 等。

我们的独特点

  • 不刷机、可逆：原厂系统完全保留；不想要了删掉子系统即可。
  • 门槛极低：电脑只要 adb；通用型还提供完整离线安装包（自带系统+依赖，盒子无需联网）。
  • 多机型：同一套方法适配多种盒子（已覆盖 魔百盒 CM201-1 / CM201-2 / M301H 等海思 Hi3798MV300）。
  • 开源：MIT 许可，源码 + 教程全公开，欢迎二次开发。

我们不适合 / 做不到的

  • 要多盘 RAID、快照、数据冗余 —— 请用品牌 NAS 或开源 NAS 系统。
  • 要影音实时转码、多用户高并发 —— 老盒子 CPU 不够。
  • 要把盒子当纯 Linux 主机、随意换内核/装任意软件 —— 那属于"刷机流派"。
  • ⚠️ 别把重要数据放在盒子 NAS 上（单盘、无冗余、老系统），当"便利/临时"用最稳妥。
结论：品牌 NAS / 开源 NAS 系统 = 为"存储"而生的专业设备/系统； 刷机式盒子系统 = "换底"（更强更自由，但要刷机、丢原厂功能、有风险）； 我们 = "加装"（用吃灰盒子搭一个够用的轻量小服务器，稳、省、可逆、还留原厂）。

常见问题

需要对电脑系统有要求吗？

几乎没要求。Linux / macOS 最好用（装个 adb 即可）；Windows 也能用（在 WSL 或 Git Bash 里跑脚本，或照教程手动敲 adb 命令）。与电脑架构（x86/arm64）无关。真正"挑系统"的是盒子（Android + 对应的架构，如 armv7/armhf）。

这和"盒子刷机变 NAS"是一回事吗？

不是。刷机是把盒子系统整个换掉（纯 Linux）；我们是不刷机，在原厂系统里 chroot 一个子系统和我们的服务。

数据安全吗？

盒子方案多为单盘、无 RAID、老内核，不适合放重要数据。要可靠存储请用专业 NAS。
