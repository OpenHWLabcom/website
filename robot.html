获取控制权限科沃思八界机器人

八界（mvp03 六轴机械臂 + 升降立柱 + 头部俯仰 + 夹爪）的控制接口默认只对实验室网络与授权合作方开放。按下面流程申请，通过后会拿到设备地址、账号与控制台权限。

  1. 具备条件：加入 OpenHW Lab 线下实验室网络，或已购买 / 借用八界设备。
  2. 提交申请：邮件说明 单位 / 联系人 / 设备型号 / 使用场景 / 网络环境。
  3. 审核与授权：确认用途与安全条件；按需开通 Jetson 控制台、机器人局域网访问、下板 SSH。
  4. 安全确认：阅读并确认运动安全规则（急停、限位、抓取铁律）。
  5. 获取文档与联调：下载控制接口文档；我们提供联调支持。

三步跑起来：
  1. 解压源码包，按你的环境改 host/serve.sh 里的路径与 ROBOT_HOST / ROBOT_PW。
  2. 上位机执行 bash host/serve.sh，打开 http://<jetson-ip>:8790/robot_home.html。
  3. 下位机放好 lower/jogd，启动 jtstream.py 即可联通 ROS 2。
