怎么用（三步）

  1. 下载你要的方案 .zip，解压。
  2. 看里面的 安装教程.pdf（图文，约 30–60 分钟）。
  3. 连上盒子（开 ADB 调试），跑 安装文件/一键安装.sh <盒子IP>，或照教程手动装。
前提：盒子已 root 且能开 ADB。
本方案不刷机、不改系统分区，卸载 apk / 重新启用被禁用的应用即可恢复，随时可还原。

常见问题

会不会联网 / 上传隐私？

所有功能都在设备本机运行，不上云。只有你主动配置的「手机互传」「远程查看」「告警推送」走你自己的网络。

支持哪些盒子？

已 root 的安卓机顶盒（Android 4.4+，armv7 / arm64）。实测：海思 Hi3798MV100、中兴微 ZX296715。其它机型大概率可用。

要花钱吗？

完全免费、开源（MIT）。

装坏了怎么办？

不刷机、不改系统分区，卸载 apk / 重新启用被你禁用的应用即可恢复。

我可以贡献 / 二次开发吗？

当然。每个包里都有「开发者资料/源码」，仓库也放源码与教程。欢迎提 issue / PR。
